# IDEAL Embedded Systems Portfolio
This portfolio highlights selected projects and code samples relevant to the IDEAL Studentship in On-Device Monitoring and Adaptation Design for Embedded Systems at the University of Essex.

## 📌 1. IoT & Embedded Systems Experience
### Phytotron Environmental Monitoring System
- Designed and implemented an IoT-based phytotron for environmental sensing and automated control.
- Demonstrates experience with embedded reasoning, sensor integration, and device-level logic.
- Shows ability to design adaptive behaviour loops suitable for embedded monitoring systems.

## 📌 2. Machine Learning & Intelligent Diagnostics
### Heart Disease Prediction (Comparative ML Study)
- Implemented multiple ML models with preprocessing, feature selection, and evaluation.
- Demonstrates competence in designing lightweight inference pipelines usable for on-device diagnostics.

## 📌 3. Big Data & Distributed Systems
### MapReduce Patient Record Classification
- Developed a fully distributed classification task using MapReduce on YARN.
- Shows large-scale data handling and analytical processing—useful for device behaviour modelling.

## 📌 4. Optimisation & Algorithms
### Nature Inspired Algorithms
- Implemented optimisation techniques such as Newton–Raphson.
- Demonstrates algorithmic reasoning and mathematical modelling.

## 📌 5. NLP & Embedded Intelligence
### AI-Powered Proposal Generator (MSc Dissertation)
- Developed an NLP-driven content generation tool.
- Shows ability to integrate intelligent algorithms in real-world workflows.
